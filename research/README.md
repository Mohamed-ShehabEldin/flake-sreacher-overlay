# Research archive

This directory preserves historical implementations, exploratory scripts, and
reference data. It is not imported by the runtime application.

- `legacy/auto_scan_v0/`: complete earlier Auto Scan implementation.
- `legacy/auto_scan_v1_metadata/`: the former v1 notes and workspace metadata.
- `experiments/auto_scan_v1/`: one-off image-processing and model experiments.
- `reference_data/`: tracked datapoint JSON and RGB comparison material.

The files were relocated without changing their contents. Local image datasets
remain at their existing ignored paths and are outside this cleanup milestone.
